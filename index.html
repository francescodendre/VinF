    Impostazioni

    L'app avvia la ricerca sul tuo repository GitHub e ne legge i risultati. Per farlo le serve un codice di accesso, che resta solo su questo iPhone.

    Come creare il codice
    1. Apri questa pagina di GitHub.
    2. In Token name scrivi VinF. In Expiration scegli la durata più lunga disponibile.
    3. In Repository access scegli Only select repositories e seleziona il tuo repository.
    4. In Permissions, sotto Repository permissions, imposta Actions su Read and write e Contents su Read-only.
    5. Premi Generate token, copia il codice che inizia con github_pat_ e incollalo qui sotto.

    Le ricerche già scaricate restano salvate su questo iPhone.
